# Inquiry Letters U2

Website: https://ij-teacher.github.io/inquiry-letter-u2/

English-only teaching website in the required order: U2-1, then U2-2. U2-1 retains comprehension, matching and gap-fill exercises; IV and V are omitted. U2-2 includes comprehension, True/False, matching, gap-fill, and the provided letter template. Exercises are native, editable webpage content.

Code: index.html, style.css and app.js. Lesson texts and answer keys: data/lessons.json. Source template: data/template.txt. QR code: qr-code.svg.

The original Word documents are stored only in the private repository ij-teacher/inquiry-letter-u2-materials and are not available from this public website. Written responses are self-reviewed against model answers. Objective matching, gap-fill and True/False responses are checked in the browser. Answers are not submitted to a server.

To edit content, update the data files on main. GitHub Pages serves the repository root. Source materials retain their authors’ rights.

The homepage is a lesson menu. U2-1 opens u2-1.html, and U2-2 opens u2-2.html. The Letter template section has been removed from the website.
